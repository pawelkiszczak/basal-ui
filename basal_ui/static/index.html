File format and statistics

One simple item ({"state", "question", "options", "gold"?}) or one /v1/systemone request per line; one answer per line in the same order (format: docs/SERVING.md#inference-on-a-jsonl-file). Batch requests go straight to the model: they are not counted in the statistics or the history.

How inspection works

basal-viz loads the bf16 PyTorch weights of basal-1.0, basal-1.5, basal-2.0 or basal-omni into basal-ui’s process (counted in the memory budget) and shows the prompt of every option order, its tokens, the decision after every layer and the calibration. Inspect this decision in the Playground sends the request here and lists what differs from the served decision.
